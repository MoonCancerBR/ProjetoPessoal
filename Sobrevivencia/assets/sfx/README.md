# assets/sfx/

*(Pasta planejada — ainda vazia)*

Efeitos sonoros do jogo.

## Conteúdo Futuro

- Tiro (pistola, arco).
- Golpe corpo a corpo (espada, adagas).
- Dash, pickup (XP, moeda, munição, cura, escudo, caixa de item).
- Pente vazio, recarga completa.
- Fusão de itens, level up, especial, combo ultimate.
- Morte de inimigo, alerta de mini-boss.

## Convenções

- Formato preferido: **OGG** (boa compressão + suporte Pygame nativo).
- Alternativa: **WAV** para efeitos curtos de alta prioridade.
- Nomeação: `<ação>_<variante>.ogg` (ex.: `shot_pistol.ogg`, `pickup_xp.ogg`).
