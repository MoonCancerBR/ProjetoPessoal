# documentacao/

Documentação **técnica e de design** do projeto Sobrevivência.

## Arquivos

| Arquivo | Função |
|---|---|
| `gdd_sobrevivencia.md` | Game Design Document completo — cópia canônica com visão geral, mecânicas, personagens, inimigos, itens, progressão, multiplayer, controles, arquitetura técnica e roadmap. |
| `estrutura_projeto.mmd` | Diagrama Mermaid interativo da árvore de diretórios com responsabilidades detalhadas de cada pasta e arquivo. |
| `RESUMO_PROJETO.md` | Guia técnico rápido — mapeamento de arquivos, funções essenciais, arquitetura de interação e lógica de gameplay por diretório. |
| `README.md` | Este arquivo. |

## Manutenção

Qualquer mudança estrutural no projeto (nova pasta, novo módulo, refatoração) deve ser refletida nos três documentos acima para manter a rastreabilidade.
