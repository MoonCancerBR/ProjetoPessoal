# HUD e Status

Destino para gerenciamento em tempo real de atributos, cooldowns, buffs,
debuffs, status do Calice/Omni e overlays de multiplayer.

Subpastas alvo:

- `hud/`
- `menus_tempo_real/`
- `atributos/`

O render visual pode continuar em `presentation/` ou ser espelhado ali com uma
fachada fina chamando estes modelos de status.
